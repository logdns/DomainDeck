# 发布前专项安全检查

beta.5 追加检查：反向代理可通过 `DOMAINDECK_PUBLIC_ORIGIN` 明确配置唯一可信站点，精确匹配协议、域名与端口，不信任任意转发头。非法配置在数据初始化前拒绝；未配置继续要求 Origin 主机与 Host 一致。回归覆盖改写 Host 的代理登录/退出、其他域名、HTTP 降级、错误端口、伪造转发头，以及配置在重装后的保留。健康检查不承担登录验证，代理登录另用虚构账户测试。

beta.3 追加检查：迁移受限角色保留原权限，不附加 viewer 默认权限；非管理员的账户写权限不能创建/修改/重置/删除管理员；旧提醒状态保留去重且日志脱敏；自定义模板认证及价格路径有专门夹具。数据库新增 migration 5，不重写已发布的 migration 1–4。演示绑定回环、拒绝已有目录，替换服务商/通知传输并禁用外部 DNS 和在线更新。桌面入口改用 Node + 系统浏览器。

范围：Node 重构中的初始化、密码、会话、权限、SQL、服务商凭据、外部请求、静态界面、更新 bundle 和 CI 发布边界。此文件描述具体控制和回归覆盖，不宣称完成全代码库独立渗透测试。

| 边界 | 已实现控制与验证 |
| --- | --- |
| 首次访问 → 管理员 | 每次新建数据目录生成随机密码，0600 文件；不覆盖已有用户 |
| 密码 → 会话 | 带独立盐的异步 scrypt；随机 256-bit 会话令牌；数据库仅存 SHA-256；12 小时过期；退出删除会话 |
| 账户修改 → 旧会话 | 更新资料撤销目标账户全部会话；编辑自己需当前密码；不能禁用最后一位管理员 |
| 只读 → 写权限 | 每条路由检查权限码；只读基础角色可附加自定义权限；审计、财务、账户数据分别授权；权限改变撤销会话 |
| HTTP 输入 → SQL | 所有业务字段使用预编译参数；版本迁移与批量导入事务；限制请求、响应、分页和登录并发 |
| 凭据 → 页面/日志 | 注册商和通知 AES-256-GCM 加密；主密钥独立 0600 文件；已有密文时禁止生成替代 key；列表不返回凭据；错误不回显原始响应 |
| 服务商 → 网络 | 内置服务商固定官方 API；声明式服务商和 Webhook 仅公网 HTTPS 443，检查全部 DNS 结果并固定连接 IP；禁止重定向；20 秒超时；4 MiB 响应上限 |
| 服务商声明 → 执行 | JSON/XML 模板而非脚本；禁止 DTD/实体声明；限制 XML 深度、响应大小、分页次数、路径、认证形式和递归成本查询 |
| 用户确认 → 扣款 | 默认关闭计费；精确年限报价核对；显式确认；Porkbun 成本整型美分并复核价格；订单先持久化后提交，唯一请求 ID；结果不明不自动重试并阻止创建重复未决订单 |
| 通知配置 → 发信 | 公网 DNS/IP 固定、TLS 465 或 STARTTLS 587、证书校验、加密后认证；邮件地址拒绝 CRLF；成功后持久化去重，配置加密、日志脱敏 |
| 旧 JSON → SQLite | 新目录导入；源文件只读；账户散列格式检查、管理员保留、所有表事务回滚；卡号裁剪为末四位；计费和自动提醒保持关闭 |
| 持久化文本 → 浏览器 | 所有动态 HTML 统一转义；CSP 禁止内联脚本；无 CORS；拒绝异源 API 请求；token 仅 sessionStorage |
| GitHub → 程序目录 | 固定仓库和 Node 3.x 频道；HTTPS 主机白名单；下载大小和超时上限；GitHub 摘要校验；bundle 路径白名单；原子切换；数据库备份 |
| 源码 → 发布 | 源码允许清单，不包含历史 data/；Actions 固定提交的第三方 action；测试容器无外网、只读源码/工具链、空环境及资源上限；双架构包一致后才发布 |

已知限制：内存登录限流按 TCP 来源地址，反向代理后共享一个来源，可能导致同时登录的用户共同限流；不信任任意 `X-Forwarded-For`。单进程部署，不支持数据库多进程共享。管理员在线更新相当于授权从固定仓库执行新代码；依赖 GitHub 账户与仓库发布权限的安全。更新没有独立签名/透明日志或自动健康回滚。应通过 HTTPS 代理访问，不把 SQLite、密钥和备份放入公开目录。

自动测试覆盖数据库迁移及 beta.1 schema 升级、密码、初始化、生产入口、权限、加密、服务商模拟响应、幂等扣款与失败核对、离线迁移、七种通知、SMTP 加密、更新成功/失败和中英文页面模板。具体测试数量和通过结果以当前 Actions 记录为准，源码中的测试清单可复查。

尚未验证：真实浏览器的多视口布局、真实注册商凭据/扣费/外发通知、真实 Linux/systemd 环境启动与开机自启、外部独立安全审计。支付和通知测试只使用模拟数据；SMTP 对话测试注入模拟 socket，不等于生产邮件投递认证。自定义服务商声明由高权限操作者维护；即使限制公网 HTTPS，仍能向指定公网服务传送其配置的凭据，因此只导入可信声明。旧 Go 演示环境、桌面壳和任意更新 Feed 未纳入 Node 运行时。
