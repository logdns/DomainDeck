# 专项安全检查

范围：既有账户、权限、凭据、服务商请求、交易、通知及发布控制，以及本次 Board UI 与 Ant Design Pro 模板差异。记录描述源码控制和自动回归，不代表独立完整审计或真实服务商交易认证。

## 本次改动

Board UI 复用 Vben 已授权菜单、Pinia 概览数据和同源请求层。React 只接收展示模型与操作回调，不接收认证令牌、服务商凭据或另建网络客户端。快捷操作按权限展示，DNS 无读取权限时统计入口禁用；后端与路由守卫继续独立授权。退出登录重置用户和业务状态；模板选择只在浏览器记录界面名称。

Ant Design Pro 模板复用相同的授权菜单和概览 store；导航根据已过滤的访问菜单生成，计费和 DNS 数值及辅助文案遵循权限门控。只读浏览器角色不含 `dns:read`，回归验证 Pro 欢迎区与指标卡显示占位值、隐藏 DNS 导航且不显示活动区域数量。所有业务跳转仍经路由守卫和后端授权。模板为基于官方 Workplace 页面结构的 Vue/Ant Design Vue 实现，未载入 React 示例中的虚构用户或活动数据，也不新增 API/凭据访问路径。

React 组件以文本节点展示域名、服务商和用户资料，不使用原始 HTML。服务商分布使用 Map 避免 `__proto__`、`constructor`、`toString` 等名称干扰计数。Vue 管理 React root，卸载时解除事件处理及订阅；作用域样式不修改后端安全策略。单元回归覆盖文本转义、特殊名称、错误/空数据和授权导航；浏览器回归覆盖模板切换、只读菜单、退出重登与两种模板的更新操作。

新增 React/React DOM 版本在锁文件中固定；不运行第三方 BoardUI CLI，不包含商业 Pro 代码。免费组件适配来源固定提交，MIT 通知进入完整包和更新 bundle。公开文件特征扫描和包内容检查排除真实数据与凭据。

## 保留的接入控制

接入指南由服务端提供，页面使用 Vue 文本转义。所有文档、凭据入口、步骤和字段链接只允许 HTTPS，拒绝带用户名/密码的 URL 以及 javascript/data/HTTP。自定义模板覆盖预设时不继承内置指南，防止把不同认证方式解释成官方预设。回归覆盖五家指南完整性、链接过滤、模板隔离及浏览器弹窗实际展示。

指南不会改变 Token 权限或自动进行交易；建议按用途最小授权。输入秘密保留密码框行为，列表接口不返回凭据，编辑留空保留密文。文档链接指向官方站点，API 访问仍执行既有网络限制。

## 控制和验证

| 边界 | 已实现控制 |
| --- | --- |
| 初始化与认证 | 随机管理员密码、0600 文件；独立盐异步 scrypt；256-bit 随机会话，数据库仅存摘要；过期和退出撤销 |
| 账户与权限 | 每条路由校验权限，财务/审计分别授权；权限变化撤销会话；保护最后管理员及管理员管理权限 |
| SQL 与导入 | 预编译参数、事务迁移；导入只写全新目录，异常回滚，源快照只读 |
| 凭据与日志 | AES-256-GCM，独立 0600 主密钥；密文存在但密钥丢失时拒绝生成替代 key；错误与日志脱敏 |
| 对外网络 | 固定官方 API；自定义服务商/Webhook 仅公网 HTTPS 443，检查全部 DNS 并固定 IP；禁止重定向；超时和响应上限 |
| 声明式模板 | JSON/XML，不执行脚本；拒绝 DTD/实体，限制深度、分页与响应大小 |
| 交易 | 计费默认关闭；报价和年限复核、二次确认、持久化唯一请求 ID；不确定结果阻止自动重复扣款 |
| Cloudflare 转入 | 提交端复核 Zone active/DNSSEC disabled；明确费用未知；EPP 只在内存编码发送；未决订单先核对 |
| 通知 | SMTP TLS/STARTTLS 和证书验证；拒绝 CRLF；配置加密、成功去重；日志不含秘密 |
| 浏览器 | Vue 转义、CSP、同源 API；公开 Origin 精确匹配，不信任任意转发头；CSV 过滤公式前缀 |
| 在线更新 | 固定 GitHub 仓库和频道、主机白名单、摘要/版本/路径/大小校验；检查十分钟过期；下载与确认安装分开；数据库备份和原子切换 |
| CI 发布 | 固定 Action 提交；依赖准备与禁网执行分开；只读源码、空环境、资源限制；测试不注入发布 token；双架构包一致后发布 |

## 依赖和限制

上一版生产依赖扫描为 **0 critical、0 high、5 moderate、2 low**；本版重新执行 `pnpm audit --prod --audit-level high`，以 Actions 实际输出为准。已有中低危公告涉及 smol-toml、serialize-javascript、postcss-selector-parser、deepmerge、glob、minimatch，路径在源码检查、样式或构建工具，不进入零 npm 依赖的 Node 服务；仍作为已知限制保留，不用强制跨主版本覆盖掩盖。React 在浏览器运行，新增依赖也纳入门禁，不以服务端零依赖替代前端审计。

仅支持单进程使用一个数据目录。反向代理后登录来源可能共享限流；不信任任意 X-Forwarded-For。Vben 浏览器缓存混淆不是保密措施，仍需防止同源脚本注入。自定义模板能向其配置的公网服务发送凭据，只导入可信声明。

更新依赖 GitHub 仓库发布权限，尚无独立签名、透明日志或自动健康回滚。运行数据、密钥和备份不得放入公开目录。真实扣费、第三方凭据、外部通知、实机 systemd 开机自启及独立渗透测试不在模拟验证范围内。具体测试结果以当前 Actions 和发布包复验记录为准。
